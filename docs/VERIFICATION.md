# 검증 안내서

> 30초 안에 통과 여부를 확인할 수 있도록 작성했습니다.
> 설치할 것은 없습니다. 주소를 열면 바로 동작합니다.

## 어디로 가나요

공개 주소: **https://myeongjundev.github.io/t03-card-studio/**

저장소: https://github.com/myeongjundev/t03-card-studio

## 무엇을 하나요

첫 화면 왼쪽이 **편집**, 가운데가 **미리보기**, 오른쪽이 **템플릿**입니다.
아래 3단계면 충분합니다.

1. 왼쪽 **문구** 칸의 글자를 아무거나 고칩니다.
2. 가운데 위쪽에서 **4:5** 또는 **9:16** 을 누릅니다.
3. 가운데 오른쪽 **이미지 다운로드** 를 누릅니다.

## 무엇이 보이면 통과인가요

| 단계 | 통과 기준 |
|---|---|
| 1 | 버튼을 따로 누르지 않아도 미리보기 글자가 **즉시** 바뀝니다. |
| 2 | 미리보기 모양이 정사각형 → 세로형으로 **즉시** 바뀝니다. |
| 3 | PNG 파일이 내려받아지고, 열어 보면 **미리보기와 똑같습니다.** |

미리보기와 파일이 같은 이유는 두 결과를 맞춰 놓은 것이 아니라,
미리보기 캔버스를 그대로 파일로 만들기 때문입니다. 같은 픽셀입니다.

### 조금 더 보실 경우

- **템플릿** — 오른쪽에서 이름을 적고 `현재 설정을 템플릿으로 저장`.
  목록에 생기고 `불러오기 / 수정 / 삭제` 가 모두 동작합니다.
  **새로고침해도 남아 있습니다.**
- **JSON 백업** — `JSON 내보내기` 로 파일을 받고, 그 파일을 `JSON 가져오기` 로 넣으면 복원됩니다.
- **잘못된 JSON 보호** — 메모장으로 아무 `.json` 파일을 만들어 내용을 `{깨진` 이라고 적고 가져오기를 해 보세요.
  오류 이유가 나오고 **기존 템플릿은 그대로 남습니다.**
- **긴 문구** — 문구를 아주 길게 넣거나 글자 크기를 크게 올리면,
  화면 밖으로 잘리지 않고 크기를 자동으로 줄인 뒤 그 사실을 알려 줍니다.
- **링크 공유** — 미리보기 위 `링크 복사` 를 누르면 주소가 복사됩니다.
  그 주소를 새 창에 붙여 넣으면 같은 카드가 그대로 열리고 바로 수정할 수 있습니다.
  서버는 쓰지 않습니다. 설정이 주소 안에 들어 있을 뿐입니다.
  (배경 이미지는 담기지 않습니다. 주소 길이 한계 때문입니다.)
- **온라인에서 보여줄 모습** — 왼쪽 맨 위 `기본` 을 눌러 보세요.
  레이아웃만 바뀌고, **화면 비율과 쓰던 문구·이미지는 그대로 남습니다.**
  대신 미리보기 위에 `이 조합엔 9:16 추천 · 적용` 배지가 나타납니다.
  그 배지를 눌러야 비율이 바뀝니다. 누르지 않으면 바뀌지 않습니다.
- **시대 타임라인** — 사진을 하나 올린 뒤 `2004` · `2012` · `2026` 을 차례로 눌러 보세요.
  **같은 사진의 화질이 시대를 따라 바뀝니다.**

  | 시대 | 사진이 이렇게 보입니다 |
  |---|---|
  | 2004 | 그 시절 카메라로 찍은 것처럼 — 부드럽게 뭉개지고, 밝은 곳이 날아가고, 보라로 기울고, 둥근 검은 테두리가 생깁니다 |
  | 2012 | 필름으로 인화한 것처럼 — 입자가 끼고, 색이 바래고, 가장자리가 어두워지고, 날짜가 찍힙니다 |
  | 2026 | 원본 그대로 |

  아래 조합도 눌러 보세요 — `친한 친구 + 2004`, `기본 + 2012`,
  `소셜 + 2026`을 차례로 선택하세요. 같은 문구가 개인
  다이어리·프로필 카드·세로 숏폼·밈 썸네일 문법으로 달라져야 합니다.
- **이미지 끌어다 놓기** — 배경 이미지 자리에 파일을 끌어다 놓아 보세요.
  테두리가 굵어지며 놓을 수 있다고 알려 주고, 놓으면 바로 반영됩니다.
  클릭해서 고르는 방식도 그대로 됩니다.
- **이미지 복사** — 미리보기 위 `이미지 복사` 를 누르면 클립보드에 들어갑니다.
  대화창에 바로 붙여넣기(Ctrl+V) 하면 됩니다.
- **문구 끌기** — 미리보기의 문구 위에 마우스를 올리면 커서가 손 모양으로 바뀝니다.
  그대로 끌면 문구가 따라옵니다. 캔버스 밖으로 끌어도 문구는 화면 안에 남습니다.
- **가독성 검사** — 배경색을 흰색으로, 글자 색도 흰색으로 바꿔 보세요.
  `읽기 어려움 · 대비 1.0:1` 이 뜨고, 읽히는 색으로 한 번에 바꿀 수 있습니다.
  사진을 올린 뒤 문구를 밝은 곳과 어두운 곳으로 옮기면 숫자가 따라 변합니다.
  글자 아래 픽셀을 실제로 읽어서 재기 때문입니다.
- **게시 전 확인** — 미리보기 아래에서 대비·문구 크기·자동 축소·PNG 준비 상태가
  현재 카드에 맞춰 갱신되는지 확인하세요.
- **9:16 안전 영역** — 비율을 9:16으로 바꾸고 `안전 영역 가이드 보기`를 누르세요.
  하단 안내가 미리보기 위에만 나타나며 PNG 캔버스 자체에는 포함되지 않습니다.
  가이드를 켠 채로 내려받은 PNG 와 끄고 내려받은 PNG 는 바이트까지 같습니다
  (측정 기록: [자체 점검 자료](SELF-CHECK.md) 11장).
- **되돌리기 / 다시하기** — 미리보기 위 `↩ 실행 취소` / `↪ 다시 실행` 버튼이나
  키보드 단축키 Ctrl+Z / Ctrl+Shift+Z 로 씁니다. 문구를 몇 번 고친 뒤 실행
  취소를 누르면 처음 상태로 돌아갑니다. 타이핑처럼 짧은 시간 안에 이어진
  변경은 한 단계로 묶이므로, 글자 하나마다 되돌릴 필요는 없습니다.
  (문구 입력창에 커서가 있을 때는 Ctrl+Z 가 브라우저의 텍스트 되돌리기로
  동작합니다. 카드 전체를 되돌리려면 입력창 밖을 한 번 클릭한 뒤 눌러 주세요.)
  모습·시대 선택은 빠르게 이어서 눌러도 각각 한 단계로 남습니다.
  `친한 친구` → `2004` → 문구 수정을 1초 안에 하고 되돌리기를 세 번 누르면
  문구 → 시대 → 모습 순으로 하나씩 돌아옵니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 화면이 비어 보입니다 | 새로고침(F5)을 한 번 해 주세요. |
| 이미지를 골랐는데 안 나옵니다 | PNG 와 JPEG 만 지원합니다. 다른 형식이면 화면 위에 이유가 표시됩니다. |
| 템플릿이 저장되지 않습니다 | 사생활 보호 모드에서는 브라우저 저장소를 쓸 수 없습니다. 일반 창에서 열어 주세요. |
| 새로고침하니 템플릿이 사라졌습니다 | 템플릿은 **그 브라우저에만** 저장됩니다. 다른 브라우저·기기에서는 보이지 않습니다. |
| 불러온 템플릿에 배경 이미지가 없습니다 | 의도된 동작입니다. 아래 설명을 참고해 주세요. |

## 미리 알려 드리는 제약

- **템플릿에 배경 이미지는 저장하지 않습니다.** 문구·위치·크기·색상·비율만 저장합니다.
  브라우저 저장 공간이 보통 5MB 남짓이라 1080×1920 이미지를 담으면 템플릿 두세 개로 가득 차기 때문입니다.
  불러온 뒤 이미지를 다시 고르시면 됩니다. 화면에도 같은 안내가 있습니다.
- **고른 이미지는 어디에도 전송하지 않습니다.** 모든 처리는 브라우저 안에서만 이루어집니다.
- 검사에 쓴 예제 이미지는 `scripts/make-test-images.mjs` 로 직접 만든 것이라
  사용 권한 문제나 위치 정보가 없습니다.
