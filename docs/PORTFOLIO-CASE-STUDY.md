# 또 다른 나 — 포트폴리오 사례 요약

## Signature Interaction — Temporal Scanner

정적인 시대 카드 콜라주를 사진 위의 시간 경계를 직접 움직이는 경험으로 바꿨다.
사용자는 2004·2012·2026 사이를 드래그하며 이미지 처리, 메타데이터, 문구와 화면 비율이
함께 변하는 장면을 본다. 선택한 시대는 `ENTER ERA`를 누를 때만 실제 편집기에 전달되어,
탐색 경험과 사용자의 편집 데이터를 안전하게 분리한다.

Scanner의 세로선은 장식이 아니다. 드래그 중에는 이전 시대가 base layer로 남고
다음 시대가 선의 왼쪽에서 실제로 reveal된다. 따라서 한 프레임 안에서 같은 인물의
두 디지털 문화가 동시에 보이며, 놓는 순간 가장 가까운 시대의 전체 화면으로 고정된다.


## 대표 경험 리디자인

기능이 충분한데도 첫 인상이 일반적인 편집 도구처럼 보인다는 문제를 발견했다.
그래서 기능을 더 늘리는 대신 제품의 핵심인 `한 사람 × 세 시대`를 첫 화면에서
즉시 이해할 수 있도록 2004·2012·2026 카드가 겹쳐지는 타임라인 히어로를 만들었다.

- 랜딩과 작업실을 분리해 방문자는 먼저 결과와 콘셉트를 본다.
- 현재 선택한 시대가 전체 화면의 강조색에 반영된다.
- `작품으로 보기`는 편집 도구를 숨기고 결과를 독립된 무대에 올린다.
- 모바일에서도 랜딩 → CTA → 미리보기 → 편집 흐름과 가로 폭을 E2E로 보장한다.

## 한 문장

같은 사진과 문구를 관계와 인터넷 시대에 따라 다르게 표현하는 local-first Canvas
편집기. 단일 Canvas 렌더, 손상 데이터 보존, 결정적 이미지 처리와 실제 브라우저
픽셀 검사를 제품 경험 안에 함께 설계했다.

## 문제

제작 도구는 기능이 많아질수록 첫 사용자가 무엇부터 해야 할지 모르게 된다. 또한
Canvas 편집기는 화면 미리보기와 다운로드가 달라지거나, 이미지 필터가 입력마다
반복되어 모바일에서 끊기기 쉽다.

## 판단

1. 첫 흐름을 `모습 → 시대 → 내 사진` 세 단계로 제한했다.
2. 미리보기와 PNG를 별도 렌더러로 맞추지 않고 같은 Canvas로 만들었다.
3. 시대 정보는 선언형 정의로 모으되 레이어 합성 순서는 한 함수에 남겼다.
4. 2004 이미지 보정 레이어만 캐시하고 문구는 매번 최종 Canvas에 합성한다.
5. 손상된 JSON과 localStorage는 삭제하지 않고 원본을 격리한다.

## 검증 가능한 결과

- 단위 테스트 70개
- 실제 Chromium 픽셀·모바일·상호작용 검사 12개
- Persona × Era × Ratio 27개 렌더 회귀 조합
- 미리보기와 내보낸 PNG의 다른 픽셀 0개
- 같은 설정을 다시 그린 PNG 해시 일치
- 375px 모바일 가로 넘침 없음
- 문구 변경 시 2004 이미지 보정 캐시 적중

## 면접에서 설명할 핵심

이 프로젝트의 핵심은 필터의 개수가 아니다. 사용자가 보는 결과, 다운로드 파일,
저장 데이터, 실패 복구와 테스트가 서로 다른 진실을 갖지 않도록 데이터 흐름을
줄인 것이다. 최적화도 전체 렌더러를 비동기로 바꾸지 않고 비용이 큰 중간 레이어만
재사용해, 최신 Canvas를 즉시 저장할 수 있다는 불변식을 유지했다.
