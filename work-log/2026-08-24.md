## 3. 시대 감성 재설계 (오늘의 메인 작업)

### 문제

실제 렌더 결과를 눈으로 확인한 결과, 의도한 감성이 전혀 나오지 않았다.

- 미니홈피를 의도했는데 → 얇은 회색 선 1개 + 20px 텍스트 3줄 → **문서 양식처럼 보임**
- 필름 카메라 감성 → **아예 없었음**

원인:
1. 장식이 선과 작은 글씨뿐, 미니홈피의 정체성(파스텔·카운터·BGM)이 없음
2. `persona:era` 조합에 장식이 묶여 있어 시대 자체의 정체성이 안 생김

### 해결

**시대 축을 연도가 아니라 감성으로 재정의**하고, 장식을 **Era가 주도**하게 바꿨다.

| 내부 키 | 감성 | 표현 |
|---|---|---|
| `2004` | 미니홈피 | 파스텔 카드, 이중 테두리, `MY HOME`, `TODAY 23 / TOTAL 12,458`, 다이어리 점선, ♪BGM |
| `2012` | 필름 | 검은 필름 베이스, 좌우 스프로킷 홀, `COLOR 400` / `12A →`, 비네팅, 주황색 날짜 각인 `'04 8 24` |
| `2026` | 숏폼 | 하단 그라데이션, 자막 표기 |

> 내부 키는 `2004`/`2012`/`2026` 그대로 유지했다.
> **기존 JSON·공유 링크 호환을 깨지 않기 위해서다.**

### 그리는 순서 정리

```
배경(drawBackground)
  ↓
프레임 배경(under)   ← 미니홈피 카드, 필름 베이스
  ↓
사진(drawImage)
  ↓
사진 위 장식(over)   ← 비네팅, 날짜 각인, 그라데이션
  ↓
사용자 문구(drawText)
```

`drawComposition(ctx, state, w, h, composition, layer)` 로 layer를 받아 나눈다.

### 투명 배경 결함 수정

`transparentBg`가 켜져 있으면 장식을 아예 그리지 않는다.
장식이 불투명 픽셀을 만들면 투명 PNG를 기대한 사용자가 배경이 박힌 파일을 받는다.

**불투명 비율 76.1% → 2.4%** (글자만 남음)

## 6. 작업 중 겪은 환경 문제 (내일 같은 일 반복 방지)

### Vite 캐시가 옛 모듈을 서빙

`composition.js`의 export를 바꿨는데 dev 서버가 이전 버전을 계속 줬다.
`?t=` 캐시 무효화가 의존 모듈까지 전파되며 오류가 났다.

**해결**: dev 서버 종료 → `rm -rf node_modules/.vite` → 재시작

### 브라우저 창이 표시되지 않는 환경

- `requestAnimationFrame`이 발화하지 않음 → rAF 의존 코드는 멈춤
- `setTimeout`이 최대 1초까지 스로틀됨 (`document.hidden === true`)
- 스크린샷 불가 → 픽셀 측정으로 대체
- `getBoundingClientRect()`가 0×0 반환

**해결**: 지연 없이 동기적으로 이벤트 발생시키거나, 측정값으로 검증

### base64를 손으로 옮기면 손상됨

썸네일을 확인하려고 base64를 복사해 파일로 만들었더니 깨졌다.

**해결**: 임시 수신 서버(포트 5199)를 띄워 브라우저가 직접 POST하게 함.
확인 후 서버는 정리했다.

## 8. 절대 깨뜨리면 안 되는 불변식 (내일도 유지)

1. **Preview = Export** — 미리보기 Canvas를 그대로 `toBlob()`. 다시 그리지 않는다.
2. **JSON은 전체 검증 후에만 저장** — `schema.js`는 저장소에 접근조차 안 하는 순수 함수
3. **오류가 사용자 데이터를 지우지 않는다** — 손상 저장소는 `.corrupt-<시각>`로 격리
4. **Canvas 렌더는 동기 실행** — rAF는 백그라운드 탭에서 멈춰 빈 이미지가 저장됨
